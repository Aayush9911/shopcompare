# ShopCompare beginner project

## Run it

1. Open this folder in VS Code: **File → Open Folder**.
2. Open `index.html`.
3. Click **Go Live** at the bottom-right.
4. Test search with `iPhone`, `laptop`, or `headphones`.
5. Test **Add order** and **Create price alert**. Refresh the browser: your added order remains because of `localStorage`.

## Files

- `index.html`: webpage content
- `style.css`: colours and layout
- `app.js`: data and button functionality

This is frontend-only. Do not use scraping or ask users for marketplace passwords. Real price/order integrations need permitted APIs and explicit account authorization.
